# Alter

Alter is a guided GCSE study and mastery platform for UK students. It aims to reduce the mental load of deciding what to study by providing a structured route, tracking performance, and prescribing appropriate next steps.

The initial focus is **AQA GCSE Mathematics (8300), Higher tier, for Year 11 exam-year students**, with eventual coverage of the complete Higher Maths specification. The planned experience is a laptop-optimised responsive web application that preserves tablet compatibility from the beginning.

## Project status

Alter is at the product-definition stage. Implementation technology has not yet been selected, and no application has been scaffolded. There are no installation or run instructions yet.

Read the [product brief](docs/product-brief.md) for confirmed product decisions, the learning and progression model, proposed MVP direction, risks, and unresolved questions.

The core learning loop is diagnosis → recommended topic → lessons and worked examples → guided practice → mandatory homework → mastery assessment → progression → retention review.

Alter is an independent project and is not affiliated with or endorsed by AQA.
